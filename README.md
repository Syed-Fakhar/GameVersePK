## 📖 Overview

GameVerse PK is a modern gaming eCommerce website designed for gamers in Pakistan. The platform allows users to browse and explore gaming consoles, gaming chairs, gaming PCs, accessories, monitors, keyboards, mice, headsets, and controllers.

The project focuses on creating a premium gaming-themed user experience with modern UI/UX principles, interactive elements, and a clean desktop-first design.
